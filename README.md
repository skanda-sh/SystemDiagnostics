# SystemDiagnostics

A Python-based RGB ASCII video renderer with synchronized audio playback.

## Features
- RGB ASCII video rendering
- Three selectable video modules
- Random video selection
- Original audio playback
- FFmpeg-powered video decoding

## Requirements
- Python 3
- FFmpeg and FFplay

## Setup
Place three video files in the application directory:

- assets_cache.mp4
- module_data.mp4
- system_core.mp4

Run the application:

py display_engine.py
